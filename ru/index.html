Приложение виртуализации химических реакций

  • Платформа: Windows
  • Исходный код: GitHub

На сцене имеются контейнеры для реактивов (колбы, пробирки) и станция реакций с устройствами для воздействия на станцию (электричество, тепло, свет). В меню можно перезапустить сцену, изучить список веществ и реакций, заполнить шприц выбранным реактивом и создать вещества и реакции. При создании веществ можно настроить материал отображения вещества, а при создании реакции - обратимость и необходимые условия среды реакции.

Ключевые разработанные классы и системы
  • Упрощенная альтернатива UnityEngine.UI.Selectable для компенсации недостающего контроля над наследуемыми от него классами и избыточной функциональностью;
  • Панель подбора цветов, вдохновленная панелью подбора цветов Unity;
  • Интерфейсы и код редакторов веществ и реакций, динамический рендер иконок из 3D-объектов, сохранение списков в формате JSON;
  • Простая система перехода между панелями интерфейса, настраиваемая прямо в редакторе.

Приложение анимации производственного процесса цеха на основе вывода GPSS-модели

  • Платформа: Windows

В среде имитационного моделирования GPSS Studio моделируется работа цеха. Имеется множество ограничений - заготовки перевозятся термистами вдвоем, некоторые станции привязаны к роли сотрудника и так далее. По выходным данным GPSS-модели приложение воспроизводит анимацию и изменение состояний объектов цеха. На демонстрации представлена обработка двух заготовок разными технологическими процессами.

Ключевые разработанные классы и системы
  • Генерация лога имитационного моделирования технологических процессов в GPSS Studio;
  • Парсер файлов, основанный на формализованной структуре выходного лога GPSS-модели;
  • Класс StateChanger, несущий на себе изменение состояний объектов имитационного моделирования;
  • Разделение действий операторов на подклассы OperatorAction;

Приложение для расчетов режима резания станка

  • Платформа: Windows, Android

Инженерный калькулятор, предоставляющий расчеты для пяти видов обработки детали на станках технологов-машиностроителей. Ввод данных разделены на этапы, которые различаются в зависимости от вида обработки. На формах отображены поля ввода и примечания к заполнению, а иногда и используемые формулы.

Формулы, таблицы и алгоритмы расчетов взяты из книги Балабанова А.Н. "Краткий справочник технолога-машиностроителя" 1992 года.

Ключевые разработанные классы и системы
  • Системы вычислений на каждую разновидность обработки детали;
  • Репозиторий справочной информации, содержащий характеристики деталей, инструментов и т.п., а также соответствующие коэффициенты и ограничения;
  • Гибкая структура накопления данных для цепочек этапов;
  • Адаптивный размер форм и элементов интерфейса для корректного отображения в любом экране с одним из стандартных соотношений сторон.

Игра "BUZZLE PUZZLE"

  • Платформа: Android

Экспериментальная игра, игровой процесс которой заключен в сборе различных ресурсов (нектар, мед, пыльца) с сетки из сот. Соединять содержимое сот можно только одинакового типа ресурса и одинакового количества. Удерживая пустые ячейки можно сместить весь ряд сот.

Моя задача в проекте это создание основы игрового процесса: управляемая шестиугольная сетка, система случайной генерации, реализация core-механик и их визуальной отдачи.

Ключевые разработанные классы и системы
  • Шестиугольная сетка с методами управления содержимым;
  • Программный пакет для генерации последовательностей объектов основанный на весах с собственным интерфейсом в окне Inspector и различными режимами работы:
    • Режимы распределения:
      • При Default процент - шанс появления ресурса в ячейке;
      • При Spread процент - количество ресурса на всей сетке;
    • Режимы весов:
      • Default - одно значение веса;
      • Ranged - равновероятно выбирается вес из диапазона;
      • Ranged With Probabiliy - выбирается вес из промежутка с учетом кривой распределения;
  • Модульные скрипты для анимации и изменения цвета ячеек при взаимодействии с ними.
