Chemical Reaction Visualisation

  • Platform: Windows
  • Source code: GitHub

The scene features reagent containers (flasks, test tubes) and a reaction station with devices for manipulating the station (electricity, heat, light). The menu allows to restart the scene, explore the list of substances and reactions, fill a syringe with the selected reagent, and create substances and reactions. When creating substances, you can customize the display material for the substance, and when creating a reaction, you can customize the reversibility and required reaction conditions.

Key developed classes and systems
  • A simplified alternative to UnityEngine.UI.Selectable to compensate for the lack of control over classes inherited from it and redundant functionality;
  • Color picker panel inspired by Unity's color picker panel;
  • Interfaces and code for editors of substances and reactions, dynamic rendering of icons from 3D objects, saving lists in JSON format;
  • A simple system for switching between UI panels, customizable directly in the editor.

Animation application of the production process of a factory based on the output of a GPSS model

  • Platform: Windows

The GPSS Studio simulation environment models different technological processes. There are numerous constraints - workpieces are transported by heat treatment operators in pairs, some stations are assigned to specific employee roles, and so on. Using the GPSS model's output, the application animates a workflow and changes in manufactory's objects states. The demonstration shows the processing of two workpieces using different technological processes.

Key developed classes and systems
  • Generating a process simulation log in GPSS Studio;
  • A file parser based on the formalized structure of the GPSS model output log;
  • The StateChanger class, which carries the change of states of simulation objects;
  • Separating operator actions into OperatorAction subclasses;

Application for calculating machine cutting parameters

  • Platform: Windows, Android

An engineering calculator that provides calculations for five types of machining operations performed by mechanical engineers. Data entry is divided into steps, which vary depending on the type of machining. Forms display input fields, notes on completion, and sometimes the formulas used.

Formulas, tables and calculation algorithms are taken from the book by A.N. Balabanov "Brief Handbook of a Mechanical Engineer" (1992).

Key developed classes and systems
  • Calculation systems for each type of part processing;
  • A repository of reference information containing the characteristics of parts, tools, etc., as well as the corresponding coefficients and limitations;
  • Flexible data accumulation structure for stage chains;
  • Adaptive sizing of forms and interface elements for correct display on any screen with one of the standard aspect ratios.

Game "BUZZLE PUZZLE"

  • Platform: Android

An experimental game where players collect various resources (nectar, honey, pollen) from a honeycomb grid. Only identical resource types and quantities can be combined. Holding empty cells allows the entire row of honeycombs to be moved.

My task in the project is to create the basis of the gameplay: a controlled hexagonal grid, a random generation system, the implementation of core mechanics and their visual feedback.

Key developed classes and systems
  • Hexagonal grid with content management methods;
  • A software package for generating sequences of objects based on weights with its own interface in the Inspector window and various operating modes:
    • Distribution modes:
      • At Default, the percentage is the chance of a resource appearing in a cell.;
      • At Spread, the percentage is the amount of resource on the entire grid.;
    • Weight Modes:
      • Default - one weight value;
      • Ranged - a weight is selected from the range with equal probability;
      • Ranged With Probabiliy - the weight is selected from the interval taking into account the distribution curve;
  • Modular scripts for animating and changing the color of cells upon interaction.
